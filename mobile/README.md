# LincolnEstate: Resident Mobile App

The iOS and Android version of the resident app, built with Expo (React Native + TypeScript)
and Expo Router. It has the same features as the web app in `../frontend` and talks to the same
Laravel API.

## Running it

```bash
cd mobile
nvm use 22        # Node 26 doesn't run on macOS 12
npm install
npm start         # starts Expo and prints a QR code
```

- **On your phone:** install **Expo Go** from the App Store or Play Store, then scan the QR code
  (iPhone: with the Camera app; Android: from inside Expo Go). The phone must be on the same
  Wi-Fi as the computer. If it can't connect, run `npx expo start --tunnel` instead.
- **In a browser:** press `w` in the Expo terminal for a quick preview.
- **Simulators:** press `i` (needs Xcode) or `a` (needs Android Studio).

Without a backend, the app runs on sample data from `src/lib/mock-data.ts` and any email and
password will sign in. Changes last until the app is restarted.

## Connecting to the Laravel API

A phone can't reach `localhost` on your computer, so use the computer's Wi-Fi address:

```bash
# backend
php artisan serve --host=0.0.0.0

# mobile/.env (copy from .env.example)
EXPO_PUBLIC_API_URL=http://192.168.18.5:8000/api
```

Restart `npm start` after changing `.env`. The Sanctum token is kept in the iOS Keychain /
Android Keystore via `expo-secure-store`.

## Screens

| Tab / screen | File |
|---|---|
| Login | `app/login.tsx` |
| Create an account | `app/signup.tsx` |
| Home (dashboard, reminders, estate update, emergency button) | `app/(tabs)/index.tsx` |
| Activity (family check-in/out, filter by day) | `app/(tabs)/activity.tsx` |
| Estate map | `app/(tabs)/estate-map.tsx` |
| Profile: About, Family Members, Properties, Settings | `app/(tabs)/profile.tsx`, `src/components/profile/` |
| More: Finance, Store, Messages (placeholders), Settings, Logout | `app/(tabs)/more.tsx`, `app/section/[name].tsx` |

The red **SOS** button in every screen's header (and "life under threat" on Home) sends the
emergency alert after a confirmation.

## Code layout

- `app/`: screens, one file per route (Expo Router).
- `src/lib/api.ts`: every API call, mirroring `frontend/src/lib/api.ts`.
- `src/lib/types.ts`, `src/lib/mock-data.ts`: copied from the web app. Keep them in step when the API changes.
- `src/lib/session.tsx`: sign-in state. Signed-out users only see the login screen.
- `src/components/ui.tsx`: shared pieces (Card, Button, Field, Sheet, …). Colours are in `theme.ts`.

## Building for the stores

Builds run on EAS Build in the cloud, so you don't need Xcode or Android Studio on this Mac.
The project is linked to the `lincolnestate-resident` project on expo.dev, and the build
profiles are in `eas.json`.

```bash
npx expo login                                                      # once
npx eas-cli build --platform android --profile preview              # installable .apk for testing
npx eas-cli build --platform android --profile production           # .aab for the Play Store
npx eas-cli build --platform ios --profile production               # needs an Apple Developer account
```

EAS needs a git repository. Until the project is in one, prefix the commands with
`EAS_NO_VCS=1`. The Android signing key was generated by EAS and is stored on expo.dev
(`npx eas-cli credentials` to view or download it).

The bundle ID / package is `com.lincolnestate.resident` (set in `app.json`). The icons in
`assets/` are a simple LincolnEstate mark; replace them if the design team supplies final artwork.

Builds made without `EXPO_PUBLIC_API_URL` run on sample data. To build against a live server,
add the variable to the build profile in `eas.json` (`"env": { "EXPO_PUBLIC_API_URL": "https://…/api" }`).
